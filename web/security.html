Security · threat model

What we designed for — and what we did not

pwmanager is an independent project. It is not SOC 2 certified, not ISO 27001 certified, not insured, and not “unhackable”. Treat it as a careful personal tool. For primary email, banking, or work SSO, prefer a mature audited product if that is what your risk requires.

Zero-knowledge cloud

A compromise of the API database should yield emails, KDF salts, auth-key hashes, Stripe customer ids, and AES-GCM ciphertext. It should not yield master passwords, vaultKeys, or entry plaintext. That property fails if you choose a guessable master password, if the browser is compromised, or if we shipped a buggy client that uploaded plaintext (the API rejects envelopes that look like vault JSON in the clear).

Forgotten master password = permanent data loss. There is no operator recovery.

Browser cryptography

  • PBKDF2-HMAC-SHA256, 600,000 iterations, SHA-256, 32-byte salt mixed with the email via SHA-256(salt ∥ email).
  • 64 bytes derived: 32-byte vaultKey (AES-GCM-256) and 32-byte authKey (sent to the server, hashed again with Argon2id or PBKDF2).
  • AES-GCM with a random 12-byte nonce and AAD pwmanager-vault-v1.
  • IndexedDB / localStorage hold ciphertext or UI prefs, not the master password.

CLI (unchanged)

The Python vault still uses Argon2id (or PBKDF2 fallback) and Fernet plus a file HMAC. See SECURITY.md in the repository for that threat model.

What we cannot protect against

  • Malware, keyloggers, malicious browser extensions, or a rooted device.
  • Phishing that tricks you into typing the master password on a fake origin.
  • Shoulder surfing or an unlocked tab.
  • Someone who already knows a weak master password (offline brute force of ciphertext).
  • Physical memory inspection while the vault is unlocked.
  • Supply-chain compromise of the files you actually load. Pin and review the source; this site uses a tight CSP (no inline script).

Operational controls on the API

  • Rate-limited register/login (5 / minute / hashed IP).
  • HttpOnly SameSite=Strict session cookies; tokens hashed at rest.
  • Request size limits; vault blobs capped (2 MiB free path / 8 MiB Pro).
  • IPs stored only as HMAC hashes. Stripe webhooks verified with HMAC Stripe-Signature.
  • TLS is assumed in production — do not expose python saas/server.py on the public internet without HTTPS.

HIBP

Optional, k-anonymity only: the browser sends a 5-character SHA-1 prefix to api.pwnedpasswords.com. We do not proxy that request.

Reporting

Please report vulnerabilities via GitHub security advisories on the repository. Do not attach real vaults.
