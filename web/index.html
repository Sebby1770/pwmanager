How zero-knowledge works

Two keys. One of them never leaves the room.

From your email and master password the browser derives two 256-bit keys with PBKDF2-HMAC-SHA256 (600,000 iterations, SHA-256, 32-byte salt). The server can store a hash of the second key. It cannot invert the first.

  1. 01

    You invent the password

    The master password is typed into the page and used in WebCrypto. It is not posted, logged, or written into a URL.

  2. 02

    vaultKey seals the JSON

    AES-GCM-256 encrypts names, passwords, notes, and TOTP secrets in the tab. IndexedDB keeps ciphertext only.

  3. 03

    authKey proves who you are

    A second derived key is sent to register or sign in. The API hashes it again (Argon2id) and never sees vaultKey.

  4. 04

    Pro stores an opaque blob

    Cloud sync uploads {v, nonce, ct, kdf}. A server compromise should not reveal vault plaintext.

On the workbench

What the vault actually does

Local first

Create a vault without an account. Ciphertext lives in this browser until you choose to sync.

TOTP in the entry

Store a base32 secret; live codes stay on the device. The server never receives them.

Audit without exfil

Weak, reused, and ageing passwords are scored in-page. Optional HIBP uses k-anonymity (five hex chars of SHA-1).

Idle lock & clipboard

Five-minute idle lock. Copies wipe themselves after twenty seconds, matching the CLI.

Encrypted export

Download the same envelope the API would store. Restore needs the master password — there is no back door.

CLI still here

The original Argon2id/Fernet Python manager is unchanged. Same generator policy in the terminal and the browser.

Limits, said plainly

What this is not

  • Not SOC 2, ISO 27001, insured, or “unhackable”. It is an independent project by Sebby1770.
  • If you forget the master password, nobody can open the vault. That is the product, not a bug.
  • Malware, phishing, or a compromised device can still see secrets after unlock. See the threat model.
  • Not a bank, not licensed financial advice, not an enterprise SSO vault.
