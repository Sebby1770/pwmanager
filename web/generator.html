    Check against known breaches

    This is the only feature that touches the network, and only when you press the button. It uses the Have I Been Pwned range API with k-anonymity: your browser sends the first five hex characters of the password's SHA-1 hash and nothing else. The password itself, and the other 35 characters of the hash, never leave this page. Freshly generated random passwords are effectively never in a breach corpus — this is here for checking passwords you already use.

    What this page does and does not do

    • Generation is local. Every password comes from your browser's crypto.getRandomValues CSPRNG, with rejection sampling so no character is more likely than another.
    • Nothing is stored. No cookies, no analytics, no server. Only your interface preferences (theme, lengths, toggles) are saved to localStorage — never a generated secret.
    • Nothing is uploaded. A Content-Security-Policy in the page blocks every outbound connection except the HIBP range endpoint above.
    • It is a generator, not a vault. To store what you generate, use the CLI: pip install -e ".[full]", then pwmanager add NAME --gen.
    • Works offline. Save the page and it keeps working — the wordlist and all logic are bundled.

    A generated password is only as safe as where it lands. Prefer pasting straight into a password manager over retyping it, and close this tab when you are done.

    The CLI behind it

    This page shares its generator logic with the pwmanager command line tool — same alphabet, same presets, same wordlist, same entropy maths.

    pip install -e ".[full]"

pwmanager add github --gen           # creates the vault on first run
pwmanager get github --copy password # copy, auto-clears after 20s
pwmanager gen --length 20 --count 10 # the same generator, in bulk
pwmanager audit --hibp               # reused / weak / breached check
pwmanager doctor                     # self-test, incl. vault permissions
